# Portfolio

This is my personal portfolio website built with Python and Jinja2.

## Live Site
[https://kumarpiyush18.github.io/portfolio/](https://kumarpiyush18.github.io/portfolio/)

## Development
1. Install dependencies: `pip install -r requirements.txt`
2. Build the site: `python build.py`
3. Serve locally: `python -m http.server --directory docs`
